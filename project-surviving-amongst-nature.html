Surviving Amongst Nature

AI-generated image grid · DSDN142, Victoria University of Wellington · 2026

My role
Solo — concept, prompt engineering, curation & process documentation
Tools
Gemini (3.6 Thinking)
Timeframe
16 – 28 June 2026
  • Context

    A solo project for DSDN142 at Victoria University of Wellington, 16 to 28 June 2026: a repeatable recipe for AI images.

  • Challenge

    One prompt template that gives a grid of 16 to 25 images that clearly belong together, yet each is worth looking at. And document what failed.

  • Solution

    One paragraph with one variable, the object, fixed to one videogame world: Resident Evil objects built from dragonfly anatomy.

  • Result

    A grid of 23 images that read as one set. I'm not sure it stays surprising enough.

  • Learning

    Use AI as a vocabulary translator, not just an image generator.

The problem

Cohesive but not boring, and show your thinking. The brief asked for a "recipe": one prompt template with a few variable placeholders, specific enough to hold one visual identity across a 16 to 25 image grid, but flexible enough that each image is still interesting on its own.

Too loose reads as an unrelated pile. Too tight gives a set that is cohesive but dull. The brief also required documenting the recipe's development: which prompts I tested, what didn't work and why.

My role

Solo: concept, prompts, curation and documentation. I chose the concept, wrote and iterated every version of the recipe, judged each batch against the two competing goals (cohesion and interest), and documented the dead ends. All the images were made with Gemini.

The idea

Weapons, rebuilt as dragonflies. I started with Resident Evil, a game I discovered on the PlayStation 3. I was drawn to how far it is from a dragonfly: a fragile, iridescent insect against a game of weapons, blood and survival. I brought its iconic objects (a rocket launcher, a shotgun, a grenade, a potion) into a fairycore and fantasycore look, built from the anatomy of dragonflies (order Odonata).

Each image should feel like a real asset that could exist in an alternate Resident Evil, with the object's function and silhouette still recognisable.

Process

  1. 16 June

    I mixed insects with kitchen and ceramic objects and rotated through several videogames (God of War Ragnarok, Zelda, Genshin Impact, The Sims 4). The results weren't cohesive: each object looked like it belonged to a different set.

  2. 21 June

    I tightened the wording around outlines, vibrance and texture. One test that mixed in a pixel-art game broke the whole set's cohesion. I switched the variable to animals, but every result converged on the same look (mushrooms, moss, wings, similar poses). A third idea, celebrities recreating famous memes, didn't capture what makes a meme work.

  3. 26 June

    I went back to the object idea and asked AI to translate what I had in my head into precise technical vocabulary. The key decision came from this: fix the videogame to one (Resident Evil), so the object is the only variable.

  4. 28 June

    Small, deliberate framing fixes, each tested against the growing set: "it mustn't be a close-up image", then "must be captured being used", then tuning the background instruction so every image shows a different in-game setting. The recipe finally held.

Decisions and obstacles

  • Decision

    One game, one variable

    Every time the game changed, the set lost cohesion, because each game has its own aesthetic language. Fixing it made the object the only thing that varies.

  • Decision

    AI as a translator

    I had no prior experience prompting images and my vocabulary was limited. Asking AI to turn my mental picture into technical language improved the results most.

  • Obstacle

    Three dead ends

    Ceramics and insects, animals, and celebrity memes all failed before the approach that worked. I documented each one.

  • Obstacle

    A single mismatch undoes a set

    One pixel-art test showed how a single clash of aesthetic language can break the consistency of the whole grid.

Solution

A single prompt paragraph with one variable, the object. It asks for a high-fidelity 3D game-asset render of a survival-horror object (a potion, a jacket, a shotgun, a grenade and so on) built from organic, iridescent dragonfly anatomy in a soft fantasycore and fairycore look, always shown in use, in a different in-game background each time, and never in close-up.

Result & reflection

  • 23images that read as one set
  • 4documented working days: 16, 21, 26 and 28 June
  • 3documented dead ends
  • 1variable in the final recipe

The grid holds together. The turning point was fixing the videogame and only varying the object.

What I'm unsure about: whether the set also stays interesting enough to make someone want to see more variations. Fixing the recipe this tightly (same game, aesthetic and framing) bought consistency, maybe at the cost of surprise. With more time I would vary how each object is used, not only which object it is.

Most of what I learnt came from documented trial and error, since I had never prompted images before.
