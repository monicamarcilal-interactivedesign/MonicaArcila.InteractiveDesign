Surviving Amongst Nature

AI-generated image grid · DSDN142, Victoria University of Wellington · 2026

My role
Solo — concept, prompt engineering, curation & process documentation
Tools
Gemini (3.6 Thinking)
Timeframe
16 – 28 June 2026

The problem

The brief asked for a repeatable "recipe" for generating AI images — a single prompt template with a few variable placeholders, specific enough to hold a consistent visual identity across a 16–25 image grid, but flexible enough that each image still felt worth looking at on its own. The real difficulty was finding that balance: a recipe too loose reads as an unrelated pile of images; one too tight produces a set that's cohesive but boring. On top of that, the brief required documenting the actual recipe-development process — which prompts were tested, what didn't work and why — not just handing in the final grid.

My role

Solo project: I chose the concept, wrote and iterated every version of the prompt recipe, generated and judged each batch of images against the brief's two competing goals (cohesion vs. interest), and documented the dead ends along the way.

Process

My starting idea was to bring iconic Resident Evil survival-horror objects — a rocket launcher, a shotgun, a grenade, a potion — into a fairycore/fantasycore aesthetic, built from the organic anatomy of dragonflies (paleopteran insects, order Odonata). The contrast between a game about weapons and violence and a delicate, iridescent insect was exactly what drew me in.

  1. 16 June

    Started by mixing insects with kitchen/ceramic objects, rotating through several different videogames per image (God of War Ragnarok, Zelda, Genshin Impact, The Sims 4). The results weren't cohesive — each generated object felt like it belonged to a different set.

  2. 21 June

    Tightened the prompt language around outlines, vibrance and texture. One test that mixed in a pixel-art game broke the whole set's cohesion outright — that image alone showed how much a single aesthetic-language mismatch could undo the consistency I was after. Frustrated, I pivoted the variable to animals instead of objects — but then every result converged on the same look (mushrooms, moss, wings, similar poses), trading cohesion for sameness rather than genuine variation. I tried a completely different idea next — celebrities recreating famous memes (Ariana Grande, Will Smith) — but it didn't capture the meme's essence and was a dead end too.

  3. 26 June

    Went back to the ceramic/object idea, but this time asked AI to help translate what I had in my head into more precise technical vocabulary, rather than writing the recipe from my own (limited) prompting vocabulary alone. The key structural decision came from here: fix the videogame to just one (Resident Evil) instead of rotating through several, since every game switch had been breaking cohesion — the object became the only variable.

  4. 28 June

    Spent this stage on small, deliberate framing fixes: adding "it mustn't be a close-up image", then "must be captured being used", then tuning the background instruction repeatedly so each image showed a different in-game setting without losing consistency. Each tweak was tested against the growing set before moving to the next one, until the recipe finally held.

Solution

The final recipe is a single prompt paragraph with one variable — the object — fixed to one video game world (Resident Evil): a high-fidelity 3D game-asset render of a survival-horror object (potion, jacket, shotgun, grenade...) built from organic, iridescent dragonfly anatomy in a soft fantasycore/fairycore aesthetic, always shown in use, in a different in-game background each time, and never in close-up.

Result & reflection

The final grid holds 23 images that read as one set. The real turning point was fixing the videogame and only ever varying the object — every earlier attempt that changed games mid-set broke the visual cohesion, because each game carries its own aesthetic language.

I'm not fully certain I met the other half of the brief's challenge: that the set also stay interesting enough to make someone want to see more variations. Fixing the recipe this tightly (same game, same aesthetic, same framing) bought consistency, possibly at the cost of some surprise between images — something I'd like to keep refining, maybe by varying how each object is shown being used, not just which object it is.

The biggest takeaway was learning to use AI as a vocabulary translator, not just an image generator: results improved most once I asked it to convert what I had in my head into more precise technical language, rather than relying on my own (at-the-time limited) prompting vocabulary. Having no prior experience with image prompting, most of the learning came from documented trial and error — the ceramics, the animals, and the celebrity memes were all real dead ends before the approach that worked.
